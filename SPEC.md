# Электронный журнал — курсовая (упрощённая версия)

## Стек
- ASP.NET Core 8, Razor Pages
- EF Core + SQL Server (LocalDB), строка подключения в appsettings.json
- ASP.NET Core Identity для логина. Пароль БЕЗ хэширования (учебный проект) — заглушка PasswordHasher.
- Bootstrap 5, минимум JS

## Роли
- Student (по умолчанию при регистрации)
- Teacher
- Admin

## Сущности (минимум)
- ApplicationUser : IdentityUser + FullName, GroupId (nullable)
- Group : Id, Name
- Subject : Id, Name
- Lesson : Id, SubjectId, GroupId, TeacherId, Date, Topic
- Grade : Id, StudentId, LessonId, Value (int?), Type (Lesson | Homework | NA)
  - Type=NA → неаттестация, красный маркер, не идёт в средний балл
- Homework : Id, LessonId, Description, FilePath, Deadline
- Announcement : Id, Title, Text, CreatedAt, AuthorId, GroupId (nullable = для всех)

## Страницы (Razor Pages)

### Student
- /Student/Index — средний балл, % посещаемости
- /Student/Schedule — список занятий группы
- /Student/Grades — таблица занятий с оценками
- /Student/Homeworks — список ДЗ со скачиванием
- /Student/Profile — ФИО, группа (только чтение)
- /Student/Announcements — лента объявлений

### Teacher
- /Teacher/Index — список занятий
- /Teacher/Lesson/{id} — посещаемость, оценки, прикрепить ДЗ, посмотреть сданные, н/б
- /Teacher/Journal/{groupId} — таблица: студенты × занятия, редактирование inline

### Admin
- /Admin/Users — список, смена роли
- /Admin/Groups — CRUD
- /Admin/Announcements — создание
- /Admin/Subjects — список + создание предметов (название)
- /Admin/Schedule — CRUD занятий (предмет + группа + учитель + дата + тема)

### Account
- /Account/Login
- /Account/Register (присваивает роль Student)
- /Account/Logout

## Файлы
- wwwroot/uploads/{groupId}/{lessonId}/
- В БД хранить относительный путь

## Ограничения
- Простота важнее "правильности"
- Никаких JWT, внешних API, сложного JS
- Код должен компилироваться
- Комментарии короткие, по-русски
## ЖЁСТКИЕ ПРАВИЛА ПРОСТОТЫ

- Никаких паттернов Repository, UnitOfWork, CQRS, MediatR, AutoMapper.
- Никаких JWT, OAuth, 2FA, HTTPS-only, антифорджери, если это не требуется.
- Пароли хранить в открытом виде (учебный проект).
- Контроллеры и Razor Pages использовать напрямую с DbContext через DI.
- Минимум JS. Только Bootstrap 5 + встроенный JS.
- Календарь — обычная HTML-таблица, без библиотек.
- Если сомневаешься между "правильно" и "просто" — выбирай "просто".
- Комментарии — короткие, по-русски, только там, где не очевидно.
## ДИЗАЙН-ГАЙД

Общий стиль: строгий, минималистичный, серо-чёрно-белый. Никаких ярких цветов, градиентов, эмодзи, иконок Font Awesome.

### Цветовая палитра
- Фон страницы: #f5f5f5 (светло-серый)
- Карточки/панели: #ffffff (белый)
- Основной текст: #212529 (почти чёрный)
- Вторичный текст: #6c757d (серый)
- Границы: #dee2e6
- Основная кнопка (btn-primary): #212529 (чёрный фон, белый текст)
- Кнопка при наведении: #343a40
- Опасные действия (удаление, "н/б"): #dc3545 (красный, только для акцента)
- Успех (например, "Зачтено"): #198754 (зелёный, только для акцента)

### Типографика
- Шрифт: системный (font-family без изменений, Bootstrap по умолчанию)
- Заголовки: <h1> - <h3>, обычный вес (не bold), тёмные
- Основной текст: 14-15px, line-height 1.5

### Layout
- Навбар сверху: белый фон, чёрный текст, тонкая нижняя граница #dee2e6.
- Активная ссылка в навбаре: подчёркнута снизу чёрной линией.
- Контент: max-width 1100px, центрирован.
- Карточки: белый фон, border 1px solid #dee2e6, border-radius 4px, без теней.
- Отступы: 16-24px внутри карточек.

### Кнопки
- btn-primary: чёрный фон, белый текст, border-radius 4px, без тени.
- btn-outline-secondary: прозрачный фон, серая рамка, чёрный текст.
- btn-link: подчёркнутая ссылка без кнопочного вида.
- Никаких btn-success, btn-warning в интерфейсе. Только btn-primary, btn-outline-secondary, btn-danger (для удаления).

### Таблицы
- table table-sm, без полосатой раскраски (без table-striped).
- Заголовок: фон #f8f9fa, чёрный текст, font-weight 500.
- Границы: только горизонтальные, цвет #dee2e6.
- Hover на строке: #f5f5f5.

### Формы
- Инпуты: border 1px solid #ced4da, border-radius 4px, padding 8px 12px.
- Label: font-weight 500, размер 14px, цвет #212529.
- Валидация: красная рамка + красный текст ошибки (стандартный Bootstrap).

### Особые маркеры
- "н/б" (неаттестация): красный текст #dc3545, font-weight 500.
- Пропуск: серый текст #6c757d, курсив.
- Оценка 5: жирный чёрный.
- Оценка 4: обычный чёрный.
- Оценка 3: серый #6c757d.
- Оценка 2: красный #dc3545.

### Чего НЕ делать
- Никаких эмодзи в интерфейсе.
- Никаких иконок (Font Awesome, Bootstrap Icons).
- Никаких анимаций, transition, hover-эффектов кроме смены цвета.
- Никаких теней (box-shadow), кроме, может быть, лёгкой на модалках.
- Никакого тёмного режима.
- Никаких цветных бейджей (badge bg-success и т.п.).

### Кастомный CSS
Дополнительные стили писать в wwwroot/css/site.css, классы с префиксом journal- (например, journal-card, journal-table)
## РЕГИСТРАЦИЯ И ПОЛЬЗОВАТЕЛИ

- Публичной регистрации НЕТ.
- Пользователей создаёт только Администратор на странице /Admin/Users/Create.
- При создании админ указывает: ФИО, Email, Пароль, Роль (Student/Teacher/Admin), Группу (только для Student).
- Админ может редактировать пользователя (сменить ФИО, роль, группу) и сбрасывать пароль.
- Страницы /Account/Register не существует. Ссылки "Регистрация" в навбаре нет.
- Страница "Забыли пароль?" не нужна.
- Смена пароля — только через администратора (/Admin/Users/Edit). Пользователь сам пароль не меняет.

## Soft delete
- Удаление пользователей — мягкое (IsDeleted = true). Данные (занятия, оценки) сохраняются. Удалённые не показываются в списках и не могут войти.

## Известные ограничения (осознанные)
- Админ может снять с себя роль Admin через Edit (не защищено).
- У пользователя только одна роль.
- Настройки cookie-политики минимальные (учебный проект).
